# Chat rendering

Six ways to keep a long conversation responsive. Compare them in the workbench, then open `/docs` in the app for the tradeoffs.

```sh
pnpm install
pnpm seed
pnpm dev
```

Open http://localhost:3000. Seeding builds the 10,000-message conversation every implementation uses.

```sh
pnpm lint
pnpm typecheck
pnpm verify
```
